Aura Files 0.14.1 — проверки перед упаковкой
Дата: 2026-08-29

PASS:
- versionName 0.14.1 / versionCode 20.
- AndroidManifest и все XML-ресурсы синтаксически валидны.
- ArchiveBrowserActivity зарегистрирован в Manifest.
- file_paths.xml разрешает безопасный cache-path archive-preview/.
- Room SQL для расширенной коллекции «Книги» проходит SQLite syntax smoke test.
- «Книги» охватывают все расширения из встроенного Reader support list.
- В category path больше нет DocumentFile.exists() на каждый индексированный файл.
- Полная выдача категории грузится в IO, а быстрый список открывается из памяти.
- Progress индексатора ограничен по частоте обновления UI.
- Сохранённые группы дубликатов загружаются одним запросом hashedFiles вместо N+1 bySize.
- ImageViewer получает реальный список соседних фото текущей коллекции.
- При масштабе 1x однопальцевый горизонтальный жест не поглощается zoom/pan обработчиком.
- Медиа/фото/archive UI учитывают system bars.
- ZIP/TAR/TGZ/7Z/RAR имеют folder-like browse; выбранный внутренний файл извлекается только во временный cache.
- FB2.ZIP по-прежнему считается книгой, а не обычным архивом.
- Нет конфликт-маркеров и старых 0.14.0/versionCode19 меток.
- OCR engine dependencies не добавлены.
- Kotlin syntax smoke: на изменённых крупных .kt нет parser ошибок вида "expecting"/"unexpected tokens".

ВАЖНО:
Полный Android Gradle compile именно 0.14.1 в контейнере НЕ заявляется как пройденный.
Для него используйте BUILD_ON_CLEAN_WINDOWS.bat. Скачанное ранее окружение в
C:\Users\Public\AuraBuildTools повторно скачиваться не должно.

Архивы в 0.14.1 работают «как папки» в смысле просмотра дерева, навигации и открытия/
распаковки содержимого. Редактирование архива на месте (удалять/переименовывать/добавлять
внутри без пересборки архива) в эту ревизию не включено.
