# Aura Files 1.3.3 — стандартный SMB-браузер

Проблема 1.3.2: после успешного SMB-подключения remote listing рисовался внизу длинной страницы `Сеть`, ниже поиска устройств, подключений, серверов и облаков. Пользователь мог не заметить успех и повторно запускать подключение.

Исправление:

1. Удалён рендер `state.smbItems` из страницы `Сеть`.
2. Сохранённые SMB-профили с выбранной шарой открываются непосредственно в `BackendWorkspaceActivity` с `EXTRA_SINGLE_PANE=true`.
3. Для SMB без шары показывается модальный выбор найденной общей папки. После `selectSmbShare()` сохранённый профиль автоматически передаётся стандартному browser.
4. Legacy SMB session после запуска workspace закрывается без сообщения `SMB отключён`, чтобы не держать второе соединение и stale listing.
5. Ошибки `BackendWorkspaceViewModel`, ранее говорившие только про cloud backend, сделаны нейтральными для SMB/SFTP/FTP/cloud.

Протокольные операции SMB не переписывались: стандартный UI использует существующий `SmbStorageBackend` и общий transfer-core.
