Aura Files 0.14.8 — изменения
Дата: 2026-08-31

1. SFTP-СЕРВЕР НА ТЕЛЕФОНЕ
- В «Сеть» → «Создать сервер» теперь два варианта: FTP и SFTP.
- Встроен отдельный SFTP-only SSH-сервер на Apache MINA SSHD 2.19.0.
- Порт по умолчанию: 2222 (без необходимости системного порта 22).
- Настраиваются логин, пароль и режим «Только чтение».
- Командная SSH-оболочка и выполнение команд не включены: сервер отдаёт только SFTP.
- Host key сохраняется в приватной папке приложения, поэтому fingerprint не меняется при каждом перезапуске сервера.
- Подключения разрешаются только от loopback / link-local / private-LAN адресов.
- Foreground-служба держит Wi-Fi и partial wake lock аналогично FTP-серверу и показывает отдельное уведомление.
- Запуск SSHD и первая генерация RSA host key выполняются на Dispatchers.IO, чтобы не тормозить главный поток Android.
- В карточке сервера показываются sftp://IP:PORT, логин, пароль, опубликованная папка и число подключений; реквизиты можно скопировать одной кнопкой.

2. ДОСТУП К ФАЙЛАМ ДЛЯ SFTP-СЕРВЕРА
- SFTP backend работает с java.nio.Path, поэтому как серверный корень используются реальные локальные пути памяти телефона/SD-карты.
- На Android 11+ для публикации общей памяти через SFTP требуется режим Aura «Весь накопитель».
- Произвольные облачные/сетевые SAF-провайдеры (например, OneDrive как DocumentProvider) не выдаются через этот SFTP-сервер; для обычной SAF-папки остаётся FTP-сервер.

3. ИКОНКА
- Launcher-иконка заменена на выбранный пользователем вариант: открытая синяя папка, вертикально торчащая microSD-карта и буквы «Au» на папке.
- У иконки убран внешний белый фон/углы, изображение подготовлено как 512×512 PNG для launcher foreground.
- Для Android themed icons оставлен отдельный упрощённый монохромный силуэт папки + microSD.

ПРИМЕЧАНИЕ ПО ПРОВЕРКЕ
Полный Gradle compile в текущем контейнере не заявляется как пройденный: среда не разрешает DNS-доступ к services.gradle.org/Maven Central. XML и структура проекта проверяются локально; окончательную Android-компиляцию выполняет входящий в архив Windows-builder.
