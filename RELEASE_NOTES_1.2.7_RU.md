# Aura Files 1.2.7

## Изображения

- Экран «Изображения» теперь открывается общим потоком по дате, а не длинными группами, начиная с Camera.
- Добавлены быстрые фильтры: Все / Камера / Снимки экрана / WhatsApp / Telegram / Загрузки / Другие.
- «Снимки экрана» выбираются напрямую из полного индекса и больше не теряются за тысячами фотографий Camera.
- Убран жёсткий лимит 5000 для каталога изображений: выдача постраничная по 400 файлов с кнопкой «Показать ещё».
- Поиск и сортировка работают по всей выбранной подкатегории через Room, а не только внутри уже загруженной страницы.
- По умолчанию изображения сортируются по дате, новые сверху.

## Надёжность

- Большой каталог изображений больше не прогревается целиком в фоновом cache warm-up.
- Незавершённая загрузка коллекции отменяется при выходе с экрана.
- Добавлена проверка распознавания распространённых папок Screenshots.

Cloud/OAuth/SMB/SFTP/FTP и файловые transfer-core в этой версии не менялись.
