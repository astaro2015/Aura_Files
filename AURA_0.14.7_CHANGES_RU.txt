Aura Files 0.14.7 — изменения
================================

Интерфейс
---------
- Действие «Переименовать» теперь всегда доступно в нижней панели выделения — и для одного файла, и для группы.
- Для одного выбранного файла открывается обычное переименование с исходным именем; для двух и более — пакетное переименование по шаблону.
- Экран «Сеть» приведён к трём главным блокам:
  1) «Устройства рядом»;
  2) «Подключиться к» — внутри сохранённые подключения, SMB, FTP и SFTP;
  3) «Создать сервер» — внутри FTP-сервер телефона.
- Ручные SMB/SFTP-кнопки убраны из «Устройства рядом», чтобы не дублировать раздел «Подключиться к».
- Если FTP-сервер запускается, раздел «Создать сервер» автоматически раскрывается.
- Иконка приложения заменена: вместо обычной папки — фирменная A с орбитой/узлами; добавлен отдельный monochrome-вариант для themed icons Android.

Оптимизация и проверка тормозных мест
------------------------------------
- Списки файлов SMB/FTP больше не создают все строки одним большим Compose-блоком: строки отдаются LazyColumn лениво. Это заметно уменьшает лишнюю композицию в больших сетевых папках.
- Подсчёт размера папки использует FastDocumentListing и не дёргает SAF-провайдер несколькими IPC-запросами для каждого дочернего файла. Обновление прогресса ограничено примерно 10 раз/с.
- Локальная панель универсального двухпанельного режима также использует FastDocumentListing вместо серии DocumentFile getter-запросов на каждый объект.
- Корзина читает сохранённую метаинформацию без повторного разрешения каждого URI через DocumentFile, использует быстрый единичный листинг каталога и автоматически вычищает устаревшие записи метаданных.
- Экран похожих фотографий заранее вычисляет максимальную схожесть по группам вместо повторного полного прохода по всем парам при отрисовке каждой карточки.

Примечание по проверке
----------------------
В текущем контейнере Gradle 9.5 отсутствует локально, а wrapper не может скачать distribution с services.gradle.org из-за недоступности сети. Поэтому полноценный Android Gradle compile здесь не заявляется как пройденный. Выполнены статические проверки изменённых Kotlin-файлов, XML-ресурсов, структуры версии и целостности пакета.
