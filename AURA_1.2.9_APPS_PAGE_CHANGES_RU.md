# Aura Files 1.2.9 — страница установленных приложений

Дата: 2026-09-07

## Что добавлено

- В разделе **«Очистка»** появился пункт **«Приложения»**.
- Открывается отдельная страница установленных пользовательских приложений.
- Для каждого приложения показываются:
  - системная иконка;
  - название;
  - версия;
  - package name;
  - метка **APK** для обычной установки одним пакетом;
  - метка **SPLIT · N APK** для составной установки.
- Есть поиск по названию приложения и package name.

## Поделиться обычным APK

Для приложений с одним APK доступна кнопка **«Поделиться…»**.
Aura:
1. получает установленный APK через `ApplicationInfo.sourceDir`;
2. копирует его во временный каталог `cache/shares`;
3. публикует копию через существующий `FileProvider`;
4. открывает системный Android chooser (`ACTION_SEND`).

Так можно сразу отправить APK в Telegram, почту, Nearby/Quick Share и другие приложения, принимающие файлы.
Цифровая подпись пакета не пересобирается: экспортируется установленный APK как есть.

## SPLIT

Для составных приложений кнопка отправки APK намеренно не показывается. Отправка только `base.apk` дала бы часто неустанавливаемый файл.
В 1.2.9 SPLIT-приложение только честно помечается с количеством APK-компонентов.
Экспорт полного комплекта в один контейнер `.apks` и установка такого комплекта оставлены отдельным следующим этапом.

## Видимость приложений Android 11+

Чтобы страница действительно видела установленные пользовательские приложения, в manifest добавлен `android.permission.QUERY_ALL_PACKAGES`.
Это обычное разрешение без runtime-диалога, но Google Play ограничивает его использование правилами публикации. Для sideload-сборок Aura оно работает штатно; перед публичной публикацией в Google Play назначение разрешения нужно отдельно сверить с актуальной политикой магазина.
