Aura Files 0.14.9 — проверка пакета
===================================

PASS: versionName=0.14.9, versionCode=28.
PASS: стартовые карточки «На устройстве» / «Весь накопитель» показываются только когда рабочая область ещё не подключена; после успешного выбора они скрываются, а смена области остаётся в «Настройки → Область работы».
PASS: «Очистка → Рекомендации → Временные файлы» использует отдельные COUNT/SUM по полному Room-индексу, а не ограниченный Recent-кэш из 2000 записей.
PASS: «Крупные файлы» теперь действительно означает файлы >= 50 МБ; общий счётчик берётся по полному индексу, а список при открытии дополнительно перечитывается из Room.
PASS: после переноса файлов в корзину их URI немедленно удаляются из индексной таблицы, поэтому повторное открытие рекомендаций не возвращает уже удалённые записи.
PASS: при удалении из коллекции отменяется старый асинхронный запрос коллекции, чтобы завершившийся позднее запрос не нарисовал обратно удалённые строки.
PASS: после удаления totalBytes, категории, количество/объём временных файлов и число крупных файлов корректируются по реально удалённым объектам, а не пересчитываются из усечённого Recent-кэша.
PASS: если после удаления в «Крупных файлах» или «Временных файлах» остаются следующие подходящие элементы, коллекция автоматически дочитывается из обновлённого индекса.
PASS: все 14 XML (ресурсы + AndroidManifest.xml) проходят XML parse.
PASS: локальные статические assertions по новым DAO-запросам, индексации, версии, скрытию стартового выбора и синхронизации рекомендаций проходят.
PASS: изменённые Kotlin-файлы прогнаны через kotlinc без Android/Compose classpath; ожидаемо получены unresolved-reference diagnostics, при этом parser diagnostics (expecting/unexpected tokens/unclosed) = 0.

NOT RUN: полный Gradle Android compile/lint. Gradle Wrapper пытается загрузить Gradle 9.5.0, но текущая среда получает java.net.UnknownHostException: services.gradle.org. Поэтому реальную компиляцию с Android/Compose/Room classpath должен выполнить Windows-builder из архива.

Ожидаемый debug APK после Windows-builder:
BUILD_OUTPUT\Aura_Files_0.14.9-debug.apk
