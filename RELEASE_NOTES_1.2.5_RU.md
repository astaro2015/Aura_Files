# Aura Files 1.2.5

Облачный браузер приведён к стандартному интерфейсу Aura без потери особенностей облачных backend'ов.

- Яндекс.Диск и Google Drive в однопанельном режиме используют привычные заголовок, сортировку, поиск, список/плитку и выделение Aura.
- Работают создание папок, открытие файлов, свойства, переименование и удаление.
- Добавлены настоящие `Копировать` / `Переместить` / `Вставить` для облачного режима через общий transfer-core.
- Перемещение внутри Яндекс.Диска остаётся серверной операцией; копирование выполняется безопасным потоком через transfer-core с конфликтами и прогрессом.
- Удаление в Яндекс.Диске корректно обозначено как перенос в корзину Яндекс.Диска, а не как безвозвратное удаление.
- Локальные функции, которые нельзя корректно выполнить на облачном объекте, в облачном меню не отображаются.
- Двухпанельный режим сохранён для переноса между разными хранилищами.

Версия: `1.2.5` (`versionCode 125`).
