Aura Files 1.0.1 — исправления поверх GitHub-релиза 1.0
Дата: 2026-09-04
База: astaro2015/Aura_Files, commit 63773f432aa700d042b57b8f98ad3091e209ea4d

Исправлено:
- SMB больше не привязан формулировками к Windows: учётные данные могут принадлежать Windows/Samba/Linux/NAS/роутеру.
- При явно введённом SMB-логине неверный пароль больше не приводит к скрытому откату на Guest/Anonymous.
- SMB/FTP-профили сохраняются после успешного подключения; редактирование сохраняет стабильный ID и не плодит дубликаты.
- Очистка пароля FTP/SMB/SFTP действительно удаляет старый секрет из Android Keystore.
- Фото листаются в том же порядке, в каком файлы реально показаны после сортировки, фильтра и группировки.
- Видео/аудио-плейлист также наследует текущий видимый порядок вместо принудительного A→Z.
- «Очистка»: категории, крупные, временные и дубликаты считают тот же набор, который виден при текущих настройках скрытых файлов и служебных миниатюр.
- «Умный обзор» показывает полное число проиндексированных файлов, а не размер 2000-файлового UI-кэша.
- «Карта файлов» не учитывает широкую коллекцию «Книги» второй раз поверх документов.
- При выборках больше 5000 файлов интерфейс явно сообщает, что показана только часть результата.
- Room-индекс 1.0 одноразово сбрасывается при переходе на 1.0.1; после обновления нужен новый «Анализ». Реальные файлы/корзина/настройки/профили не затрагиваются.
- Windows bootstrap staging формируется только из файлов SOURCE_SHA256SUMS.txt и проверяет SHA-256 до сборки; старые исходники, оставшиеся рядом, игнорируются.
- Убраны оставшиеся пользовательские подписи «0.14» в интерфейсе расширенных настроек.

Не изменено:
- OCR по-прежнему не включён.
- SMB1 по-прежнему отключён; поддерживаются SMB2/SMB3.
- Существующие упаковочные исключения META-INF из GitHub 1.0 сохранены.
