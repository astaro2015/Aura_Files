# Aura Files 1.3.19

## Исправлено

- Исправлена причина вылета видеоплеера на Android: ARSCLib больше не упаковывает собственные заглушки Android framework и XmlPull API, конфликтовавшие с системными классами и XML-инфлейтером Media3.
- DjVu-файлы исключены из растрового предпросмотра, который не умеет декодировать этот формат и зависал на индикаторе загрузки.

Проверка воспроизведения на POCO F6 с этой конкретной сборкой ещё не выполнена. APK собран для установки и повторной проверки на устройстве.
