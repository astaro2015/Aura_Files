# Aura Files 1.3.17 — Сейф и предпросмотр

Сохранены переименование «Избранное» в «Сейф» и безопасный перенос `.AuraVault` в `.AuraSafe` из 1.3.16.

- Чтение соседних фото/видео больше не должно завершать экран необработанным исключением при недоступной папке: текущий файл остаётся открытым.
- Определение миниатюр и встроенного предпросмотра согласовано с поддерживаемыми расширениями, даже если файловый провайдер не сообщает MIME.
- Текстовый предпросмотр ограничен 32 768 символами за одно открытие вместо 300 000, чтобы уменьшить ожидание и нагрузку на разметку интерфейса.
- Android API 29 для публикации APK в MediaStore теперь явно ограждён проверкой версии системы, понятной Lint.

Автоматические тесты и сборка не заменяют проверку на конкретном телефоне. Эти исправления закрывают найденные в коде пути ошибок; без журнала устройства нельзя подтвердить, что они объясняют каждый ранее наблюдавшийся сбой.
