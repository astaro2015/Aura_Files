# Aura Files 1.2.1

Bugfix-релиз cloud OAuth поверх 1.2.0.

- Яндекс.Диск больше не должен сбрасывать device-code авторизацию после перехода на страницу OAuth и возврата в Aura.
- Google Drive больше не теряет результат системного окна авторизации после пересоздания Activity.
- После успешного Google/Yandex входа облако сразу выбирается в одной панели, локальная память остаётся во второй.
- Google access token не сохраняется на диск; добавлен только process-local cache для первого открытия Drive.
- Photoslice и отдельные облачные корзины не добавлялись.
