AURA FILES 1.0 — WINDOWS-СБОРЩИК С ВОЗОБНОВЛЕНИЕМ
=========================================================

Запустите BUILD_ON_CLEAN_WINDOWS.bat двойным щелчком.

Что изменено относительно предыдущего автосборщика:
- BITS полностью не используется;
- Invoke-RestMethod для JDK полностью не используется;
- JDK 17 скачивается напрямую через curl.exe;
- у curl нет ограничения общего времени загрузки;
- подключение может ждать до 300 секунд;
- при сетевой ошибке/timeout частичный *.part сохраняется и загрузка продолжается;
- сетевые ошибки curl повторяются, пока загрузка не закончится (Ctrl+C отменяет вручную);
- sdkmanager получает до 20 попыток для лицензий и до 30 попыток для пакетов;
- Gradle получает увеличенные HTTP connect/read timeouts и до 12 попыток сборки.

Кэш: C:\Users\Public\AuraBuildTools
APK:  BUILD_OUTPUT\Aura_Files_1.0-debug.apk

Если окно всё же сообщает ошибку, оно не закрывается само. Пришлите
BUILD_OUTPUT\LAST_ERROR.txt — там будет уже конкретный этап, а не исчезнувшее окно.
