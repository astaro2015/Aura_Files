Aura Files 0.14.2 OPTIMIZED — изменения относительно 0.14.1
Дата: 2026-08-29
versionName: 0.14.2
versionCode: 21

1. ИСПРАВЛЕНИЯ 0.14.1
- Исправлена compile-ошибка чтения одного файла из SevenZFile.
- Исправлены пропущенные duplicateOriginalUris в двух вариантах списка Recent.
- APK больше не может ошибочно классифицироваться как обычный архив из-за MIME application/vnd.android.package-archive.
- Централизовано разрешение file/document/tree URI, чтобы document URI не превращался случайно в корень SAF-дерева.

2. БЫСТРЫЕ ПАПКИ И SAF
- Для обычного file:// используется прямой java.io.File.listFiles().
- Для стандартного Android SAF используется один ContentResolver.query() на каталог вместо множества DocumentFile getter-запросов на каждый объект.
- DocumentFile.listFiles() оставлен как совместимый fallback для нестандартных providers.
- Быстрые переходы между папками отменяют устаревшие фоновые загрузки; старый результат не должен подменять новый экран.

3. ИНДЕКС И ROOM
- База индекса обновлена до schema version 2 с миграцией 1→2 без уничтожения существующего индекса.
- Добавлены readerSupported и temporaryCandidate, вычисляемые во время сканирования.
- Добавлены составные индексы под реальные горячие запросы rootId+category/date, rootId+reader/date, rootId+temporary/size, rootId+size и rootId+size+sha256.
- Убран N+1 запрос findUnchanged() для каждого обнаруженного файла: старые size/date/hash загружаются одним snapshot-запросом.
- Категории и источники считаются агрегатными SQL-запросами.
- Книги/временные открываются по индексируемому признаку, без полного LIKE-разбора таблицы.
- Сохранённые реальные группы дубликатов загружаются одним JOIN-запросом.

4. ДУБЛИКАТЫ И ХЭШИ
- Кандидаты одинакового размера получаются одним JOIN вместо запроса для каждого размера.
- Quick hash не перечитывается второй раз перед полным SHA-256.
- Обновления хэшей пишутся в Room пакетами.
- Убрано медленное форматирование каждого байта digest через String.format; общий hex helper используется в инструментах.

5. UI И COMPOSE
- Progress индексирования ограничен примерно 5 обновлениями/сек; ViewModel дополнительно защищён от слишком частых перерисовок.
- Progress передач ограничен примерно 10 обновлениями/сек, финальные/ошибочные состояния публикуются сразу.
- Производные показатели дубликатов в StorageAnalysis кэшируются для одного анализа.
- Категория сначала показывается из имеющегося memory slice, полный список приходит из Room в фоне.
- Временные файлы работают по той же схеме.
- Одновременное тяжёлое декодирование миниатюр ограничено четырьмя задачами.

6. ФОТО И МЕДИА
- Свайп изображений 1 пальцем при масштабе 1x не конфликтует с zoom/pan.
- Список соседних изображений/медиа использует быстрый листинг папки.
- Фото декодируется с учётом реального размера дисплея вместо безусловного лимита 4096 px.
- Аудио/видео начинает играть сразу; соседний playlist собирается в Dispatchers.IO и подключается после готовности.

7. АРХИВЫ КАК ПАПКИ
- ZIP/TAR/TGZ/7Z/RAR остаются browseable как дерево папок.
- Построен индекс parentPath→children; переход по подпапкам не фильтрует весь архив заново.
- Для file:// 7z читается непосредственно из исходного файла без полного копирования в cache.
- При распаковке кэшируются уже найденные/созданные каталоги.
- Буферы чтения переиспользуются внутри одной операции.
- FB2.ZIP остаётся книгой.

8. КНИГИ
Умная коллекция «Книги» включает форматы встроенного Чтеца независимо от основной категории:
EPUB, FB2, FB2.ZIP, MOBI, AZW, AZW3, PRC, DOCX, RTF, MD/MARKDOWN, TXT, HTML/HTM,
PDF, DJVU/DJV, CBZ/CBR.

9. ЧТО НЕ ДЕЛАЕТСЯ
- OCR не добавлен.
- Архивы просматриваются/открываются/распаковываются как папки, но редактирование содержимого архива на месте с его пересборкой пока не реализовано.
- Полный Android Gradle assembleDebug 0.14.2 в контейнере не заявляется как пройденный; для реальной сборки предназначен BUILD_ON_CLEAN_WINDOWS.bat.
