Aura Files 0.14.9 — изменения
Дата: 2026-08-31

1. ОЧИСТКА → РЕКОМЕНДАЦИИ
- Исправлена рассинхронизация: после удаления файлов и повторного анализа мелкая строка рекомендации больше не должна показывать старое количество/объём при пустом списке внутри.
- Статистика временных файлов теперь берётся из полного индекса Room, а не из ограниченного кэша последних 2000 файлов.
- Для крупных файлов введён реальный порог 50 МБ и отдельный точный счётчик по полному индексу. Раньше индексатор фактически подставлял просто 50 самых больших файлов независимо от размера.
- При открытии «Крупные файлы» список дополнительно перечитывается из индекса, поэтому после удаления верхней выборки могут появиться следующие подходящие файлы.
- При переносе в корзину соответствующие URI сразу удаляются из индексной таблицы; рекомендации и содержимое коллекций не ждут следующего полного сканирования, чтобы перестать видеть удалённые записи.
- Отменяется старый фоновый запрос открытой рекомендации, поэтому он не может поздно вернуть на экран уже удалённые строки; для крупных/временных файлов после удаления автоматически подгружается следующая порция, если она есть.
- Пересчёт после удаления больше не строит totalBytes/категории из ограниченного Recent-кэша: значения уменьшаются на реально удалённые объекты.

2. ВЫБОР ОБЛАСТИ РАБОТЫ
- Карточки «На устройстве» / «Весь накопитель» показываются только до первого успешного выбора области.
- После подключения папки или всего накопителя эти две стартовые карточки на главном экране скрываются.
- Сменить область работы по-прежнему можно в Настройки → Область работы: «Выбрать папку» или «Использовать весь накопитель».
- Если сохранённый доступ перестанет быть доступен, стартовый выбор появится снова.

ПРИМЕЧАНИЕ ПО ПРОВЕРКЕ
Полный Gradle compile в текущем контейнере не заявляется как пройденный: Gradle Wrapper пытается получить Gradle 9.5.0, но services.gradle.org недоступен из среды (UnknownHostException). Выполнены локальные структурные проверки, XML parse, проверка ссылок/версий и целостности архива; окончательную Android-компиляцию выполняет Windows-builder из архива.
