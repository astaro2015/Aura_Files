Aura Files 1.0.2 — исправление анализа полного накопителя
Дата: 2026-09-04
База: Aura Files 1.0.1, upstream GitHub 1.0 commit 63773f432aa700d042b57b8f98ad3091e209ea4d

Исправлено:
- Анализ в режиме «весь накопитель» больше не падает на Android/data с сообщением «доступ отозван или накопитель отключён».
- Аналогично пропускается Android/obb: эти деревья Android намеренно закрывает для перечисления содержимого других приложений даже при широком доступе к файлам.
- Пропуск сделан точечным только для Android/data и Android/obb. Обычные ошибки чтения, потеря доступа к корню и отключение SD/USB по-прежнему считаются ошибкой и не маскируются.
- После успешного анализа Aura сообщает число пропущенных защищённых папок, если такие встретились.
- Добавлен unit-test политики защищённых Android-путей.
- versionName 1.0.2 / versionCode 102.

Сохранены все исправления 1.0.1:
- SMB/FTP/SFTP профили и аутентификация;
- порядок фото/видео/аудио;
- согласованная статистика «Очистки»;
- защищённый Windows staging по SOURCE_SHA256SUMS.txt;
- NO-OCR, SMB2/SMB3.
