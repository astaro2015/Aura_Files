# Aura Files 1.2.9 checkpoint

Актуальная рабочая версия: **1.2.9 / versionCode 129**.

База: Aura Files 1.2.8 CLOUD DARK THEME FIX.

Добавлено в 1.2.9:
- «Очистка → Приложения»;
- список пользовательских установленных приложений;
- APK / SPLIT маркировка;
- количество APK в split-наборе;
- поиск по названию/package;
- экспорт и системное «Поделиться…» для single-APK приложений через FileProvider;
- `QUERY_ALL_PACKAGES` для полной package visibility на Android 11+.

SPLIT пока только определяется и маркируется. Экспорт `.apks`/установка полного split-набора не реализованы намеренно, чтобы не создавать неработающие файлы.

Существующие cloud, network, transfer, images и trash функции должны сохраняться без изменений.
