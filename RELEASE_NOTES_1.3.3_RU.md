# Aura Files 1.3.3

- SMB теперь открывается в стандартном файловом интерфейсе Aura вместо списка внизу страницы «Сеть».
- Сохранённое подключение с выбранной общей папкой открывается сразу.
- Если шара не указана, Aura сначала показывает модальное окно выбора общей папки, затем автоматически переходит в файловый браузер.
- После перехода старое служебное SMB-соединение освобождается, чтобы не оставлять два параллельных подключения.
- Никаких изменений формата Vault/APKS и cloud OAuth в этом релизе нет.
