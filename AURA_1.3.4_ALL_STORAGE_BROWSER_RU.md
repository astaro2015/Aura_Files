# Aura Files 1.3.4 — «Все»

## Что изменено

На главной странице Aura плитка «Другие» заменена на «Все». Раньше «Другие» была лишь индексной категорией файлов, не попавших в основные типы, и не давала пользователю простой способ пройти по дереву всей внутренней памяти.

Теперь Home `CategoryGrid` использует эту последнюю позицию как специальное навигационное действие:

- полный доступ уже разрешён → `FileManagerViewModel.activateFullAccess()` подключает корень общей внутренней памяти и открывает обычный браузер;
- полного доступа нет → вызывается существующий Android flow `MANAGE_APP_ALL_FILES_ACCESS_PERMISSION`; после возврата `refreshFullAccessStatus()` подключает root при успешной выдаче разрешения;
- анализ/Room-индекс для открытия «Все» не требуется.

## Важные ограничения Android

«Все» означает доступный Aura корень общей внутренней памяти (`Environment.getExternalStorageDirectory()`), а не системные `/data`, `/system` и приватные каталоги других приложений. Ограничения Android остаются в силе. Съёмные накопители/USB показываются отдельно в блоке подключённых накопителей.

Служебные `.AuraVault` и `.AuraTrash`/корзина Aura остаются исключёнными из обычного списка через `FileRepository.listChildren()`.

## UI

- название: `Все`;
- иконка: Storage;
- при наличии полного доступа: `Все папки и файлы`;
- без доступа: `Нужен полный доступ`.

В `Очистка → По типу` старая аналитическая категория `Other` оставлена отдельно, потому что там она означает именно файлы неизвестных/прочих типов, а не навигацию по диску.

Дополнительно user-facing название `Книги` изменено на `Книги`; код классификации не менялся.
