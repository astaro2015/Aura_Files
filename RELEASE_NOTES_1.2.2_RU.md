# Aura Files 1.2.2

Исправление подключения Яндекс.Диска и Google Drive по результатам реального теста на Android.

- Яндекс OAuth теперь запрашивает Client ID и Client Secret приложения.
- Yandex Client Secret хранится зашифрованно через Android Keystore.
- После успешного Yandex/Google OAuth workspace заново открывается с конкретным cloud backend, а не остаётся с двумя Local-панелями.
- Добавлена явная диагностика ошибок регистрации backend.
- Google `DEVELOPER_ERROR` показывает package и SHA-1 текущей APK-сборки.
- Google Drive 403 показывает provider message и подсказывает проверить Drive API/consent scope.
- Добавлены `CLOUD_SETUP_1.2.2_RU.md` и `SHOW_GOOGLE_OAUTH_SHA1.bat`.
- Photoslice и отдельные облачные корзины не добавлялись.
- В разделе «Сеть» добавлен отдельный 4-й пункт «Облако».
- Обычный Яндекс.Диск/Google Drive теперь открывается однопанельно; двухпанельный режим оставлен отдельным инструментом переноса между хранилищами.
- Cloud-файлы можно открывать обычным тапом: Aura временно скачивает их в защищённый cache и передаёт подходящему просмотрщику.
- Корзина Aura теперь просматривается как файловое дерево: можно входить в удалённые папки и открывать находящиеся в них файлы.
