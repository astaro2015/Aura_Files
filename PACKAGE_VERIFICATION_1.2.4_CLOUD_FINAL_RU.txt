2. Android XML parse: 14 файлов, 0 ошибок.
3. Yandex OAuth core отдельно скомпилирован kotlinc со stub org.json: OK.
4. Yandex OAuth smoke из текущих исходников: YANDEX_124_BASIC_SMOKE_OK.
   - primary host /token: https://oauth.yandex.com/token;
   - grant_type=device_code + code находятся в form-body;
   - client_id:client_secret передаются через HTTP Basic Authorization;
   - Client Secret отсутствует в form-body и в YandexHttpRequest.toString().
5. Yandex network flow:

6. Android Keystore AES-GCM:
   - CloudTokenStore, YandexOAuthSecretStore и CredentialStore на ENCRYPT_MODE не передают caller-provided IV;
   - IV берётся из cipher.iv после init и хранится рядом с ciphertext;
   - decrypt использует сохранённый IV через GCMParameterSpec.
7. Google Drive:

   - профиль создаётся только после реального Google Drive about();

8. Сверка с TeamAmaze/LaputaCloudsLib:
   - non-FOSS Google implementation также использует Google Play Services и Android OAuth registration;
   - FOSS WebView OAuth implementation неполна/не переносилась;
