Aura Files 0.14.1 — восстановление функций + UI/performance pass
Дата: 2026-08-29

1. КНИГИ
- «Книги» теперь не зависят от одной первичной категории в индексе.
- Коллекция ищет ВСЕ форматы встроенного Чтеца:
  EPUB, FB2, FB2.ZIP, MOBI, AZW, AZW3, PRC,
  DOCX, RTF, MD/MARKDOWN, TXT, HTML/HTM,
  PDF, DJVU/DJV, CBZ/CBR.
- Работает и со старым индексом: полный повторный скан только ради этого не нужен.

2. ФОТО
- Исправлено реальное листание фото свайпом.
- ImageViewer получает список изображений из текущей коллекции/папки,
  а не пытается заново угадывать соседей только через parentUri.
- Свайп работает в категории «Изображения», папках и других коллекциях.
- Исправлен конфликт жестов: при масштабе 1× один палец листает Pager, два пальца масштабируют; при увеличении один палец двигает фото.
- Исправлены отступы от status/navigation bars.

3. ДУБЛИКАТЫ
- В каждой группе помечается предпочтительная копия «★ Оригинал? · оставить».
- Это осознанно помечено знаком вопроса: одинаковые байты не позволяют математически
  доказать, какой файл был первым.
- Эвристика: Camera/DCIM/Pictures предпочтительнее; cache/temp и мессенджеры — хуже;
  затем учитывается более ранняя дата.

4. АРХИВЫ КАК ПАПКИ
- Обычный тап по ZIP / TAR / TAR.GZ / TGZ / 7Z / RAR открывает содержимое как дерево папок.
- Можно заходить во вложенные каталоги, возвращаться назад и открывать файлы внутри.
- Для открытия извлекается только выбранный файл во временный cache, а не весь архив.
- Вложенные книги/фото/аудио/видео открываются встроенными средствами Aura.
- Есть «Распаковать всё» рядом с архивом.
- FB2.ZIP остаётся книгой и открывается Чтецом, а не как обычный ZIP.
- RAR теперь также доступен для распаковки через уже подключённый junrar 8.1.0.

5. ПРОИЗВОДИТЕЛЬНОСТЬ
- Убраны тысячи DocumentFile.exists() / ContentProvider IPC при открытии категорий.
- Категория открывается сразу из памяти, полный результат из Room подменяется в фоне.
- Фильтрация и группировка полного результата перенесены на Dispatchers.IO.
- Сводки карточек категорий берутся из готовых SQL summary, а не пересчитываются
  фильтрацией списка на каждой перерисовке.
- Сортировка/фильтрация BrowserScreen закэширована через remember.
- UI-progress анализа ограничен примерно 6–7 обновлениями/сек вместо update на каждый файл.
- Загрузка сохранённых групп дубликатов теперь одним SQL-запросом вместо N+1 запросов по размерам.

6. UI
- Плеер больше не должен залезать под status bar.
- Фото-кнопки снизу учитывают navigation bar.
- ArchiveBrowser использует safe-area сверху и снизу.
