# Aura Files 1.2.9

## Установленные приложения в «Очистке»

- Добавлена страница **«Очистка → Приложения»**.
- Установленные пользовательские приложения показываются с иконкой, названием, версией и package name.
- Обычные приложения помечаются **APK**.
- Составные установки помечаются **SPLIT · N APK**.
- Для обычного APK доступна кнопка **«Поделиться…»**: Aura извлекает установленный APK во временный кэш и открывает стандартный системный выбор приложения для отправки.
- Добавлен поиск по названию и package name.
- Для SPLIT кнопка отправки намеренно отсутствует, чтобы не выдавать один `base.apk` за рабочий установочный файл.

Для полного списка установленных пользовательских приложений на Android 11+ добавлено разрешение `QUERY_ALL_PACKAGES`. Оно не требует отдельного подтверждения пользователем, но имеет ограничения политики Google Play при публичной публикации.
