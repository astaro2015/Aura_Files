# Aura Files 1.3.16 — Сейф

- «Избранное» теперь называется «Сейф» в интерфейсе и сообщениях.
- Зашифрованные файлы хранятся в скрытой папке `.AuraSafe/data` вместо `.AuraVault/data`.
- При первом открытии Сейфа или добавлении файла приложение переименовывает существующую `.AuraVault` в `.AuraSafe` целиком, сохраняя байты `.avf` и ключ шифрования прежними.
- Если обнаружены обе папки либо символическая ссылка вместо папки, автоматический перенос останавливается с сообщением. Ничего не удаляется; обе папки остаются скрытыми для обычного файлового просмотра и сетевых серверов.
- Сохранено исправление доступа к выбранной папке при восстановлении файла из предыдущей сборки 1.3.15.

Обновление устанавливается поверх прежней версии при совпадении подписи. Перед обновлением рекомендуется сохранить резервную копию важных данных. Если перенос остановился из-за конфликта двух папок, не удаляйте их и обратитесь за разбором данных.

Проверки: JVM-тесты миграции и существующий набор `testDebugUnitTest`; release APK собирается командой `assembleRelease` с тем же сертификатом, что и предыдущие локальные сборки.
