Aura Files 1.0.3

Исправления сети:
- Кнопка SMB у найденного LAN-устройства больше не запускает немедленный гостевой вход.
- Теперь открывается диалог SMB с уже подставленными именем устройства и IP-адресом; пользователь может сразу указать учётные данные.
- Сырые внутренние сообщения jCIFS вида 0.0.0.0<00>/10.x.x.x больше не показываются пользователю.
- Анализируется вся цепочка причин SMB-ошибки, поэтому LOGON_FAILURE, ACCESS_DENIED, timeout, connection refused/reset и ошибка согласования SMB2/3 получают понятные сообщения.

База: Aura Files 1.0.2 / GitHub 1.0.
