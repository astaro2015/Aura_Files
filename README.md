# Aura Files 0.12.0

Файловый менеджер для Android с лаконичным интерфейсом в духе Apple. Основное приложение написано на Kotlin и Jetpack Compose; встроенные движки чтения книг используют Java.

Разработчик: Привалов Олег.

## Что уже работает

- выбор доступной папки через системный Storage Access Framework;
- дополнительный режим полного доступа к корню общей памяти через системное разрешение «Управление всеми файлами»;
- быстрое переключение между безопасным доступом к папке и всем накопителем;
- безопасная смена подключённой папки без очистки данных приложения;
- сохранение выданного разрешения между запусками;
- навигация по папкам и поиск по текущей папке;
- рекурсивный анализ подключённой папки и поиск по всему проиндексированному дереву;
- расширенные фильтры поиска по категории, размеру и дате изменения;
- быстрые категории: изображения, видео, аудио, книги, документы, архивы и другие файлы;
- отдельные быстрые категории APK, «Загрузки» и «Камера»;
- группировка содержимого категорий по источнику: Камера, Загрузки, WhatsApp, Telegram, снимки экрана и другие папки;
- отдельная категория «Книги» и встроенная читалка EPUB, FB2/FB2.ZIP, MOBI/AZW/AZW3/PRC, DOCX, RTF, Markdown, TXT и HTML;
- встроенный просмотр PDF, DjVu/DJV и комиксов CBZ/CBR, включая запоминание позиции, закладки, заметки, оглавление и настройку оформления;
- категория «Книги» показывает все форматы встроенной читалки, включая PDF, DjVu, DOCX, RTF, Markdown, TXT и HTML;
- голосовое чтение и разрешения синтеза речи намеренно не включены;
- поиск крупных файлов и настоящих дубликатов по SHA-256 содержимого;
- наглядная карта занимаемого места по типам файлов;
- открытие файлов в подходящих приложениях;
- встроенный просмотр изображений с масштабированием, многостраничных PDF, текста, видео и аудио;
- видеоплеер Media3 с более широкой поддержкой контейнеров, полноэкранным альбомным режимом и передачей неподдерживаемого файла внешнему плееру;
- безопасные уменьшенные миниатюры изображений и видео только в сетке, с ограниченным кэшем памяти;
- полноразмерное превью в верхней части плитки, цветная рамка типа файла и выровненная нижняя строка;
- служебные изображения из `.thumbnails` скрыты по умолчанию и включаются в настройках;
- ленивое отображение больших категорий без одновременного создания тысяч строк;
- создание папок, переименование и удаление;
- безопасная корзина с восстановлением и быстрой отменой удаления;
- избранные файлы и папки, сохраняющиеся между запусками;
- пакетное переименование с поиском, заменой, префиксом, нумерацией и предпросмотром;
- копирование и перемещение файлов и папок;
- множественное выделение и изменение даты файлов;
- изменение даты через прямой файловый путь при полном доступе с резервным способом для SAF-провайдеров;
- групповое копирование, перемещение, удаление и отправка;
- автоматическая упаковка папок во временный ZIP при отправке через другое приложение;
- отправка отдельного файла или папки прямо из меню «…»;
- команда «Открыть в…» для передачи фото, видео, музыки и документов внешнему приложению;
- двухпанельный режим с независимой навигацией и копированием между панелями;
- FTP и явный FTPS (TLS): сохранённые подключения, пассивный бинарный режим, загрузка, скачивание, папки, переименование и удаление;
- поиск в текущей локальной сети компьютеров, NAS, роутеров, телевизоров и других хостов через сканирование служб, SSDP/UPnP и таблицу соседей;
- клиент SMB2/SMB3 как в Проводнике: достаточно выбрать найденный компьютер или ввести его IP, после чего Aura покажет список доступных шар;
- SMB сначала пробует Guest/Anonymous, затем введённую учётную запись; прямое `\\PC\Share` осталось в расширенных настройках; SMB1 отключён;
- FTP keep-alive каждые 25 секунд и автоматическое повторное подключение после сна или обрыва сети;
- FTP-сервер на телефоне: публикация только подключённой папки, случайный пароль, до четырёх клиентов, PASV/EPSV и режим «только чтение»;
- работа FTP-сервера с выключенным экраном через foreground-службу и Wi‑Fi lock, с постоянным уведомлением и кнопкой остановки;
- автообновляемые карточки SD-карт и USB-накопителей: Aura видит как смонтированные тома Android, так и USB Mass Storage, ожидающие монтирования;
- безопасный переход в системное управление накопителем для монтирования/форматирования средствами Android без опасной сырой записи по секторам;
- создание ZIP из одного или нескольких файлов и папок;
- безопасная распаковка ZIP с защитой от подмены путей и чрезмерно больших архивов;
- сортировка и представление списком или сеткой;
- показ и скрытие файлов, имена которых начинаются с точки;
- подробные свойства с MIME-типом, URI и вычислением SHA-256 по запросу;
- прогресс групповых операций и возможность остановить очередь между объектами;
- автоматическое скрытие всех уведомлений не позднее чем через 10 секунд;
- назначение аудиофайла мелодией звонка или звуком будильника через системное разрешение Android;
- поиск в папках скрыт по умолчанию и открывается кнопкой-лупой; представление переключается одной кнопкой между списком и плиткой;
- удаление файла из категории обновляет список на месте и не закрывает категорию;
- полноценное управление файлами в «Недавних»: меню действий, групповое выделение, отправка, дата, ZIP, свойства и переключение список/плитка;
- на главном экране вместо дублирующего списка недавних находится быстрый вход в «Избранное»;
- страница настроек из меню «…»: скрытые файлы, служебные миниатюры, превью плиток, избранное и область доступа;
- индекс анализа сохраняется на диске и восстанавливается после перезапуска приложения;
- переименование и изменение даты больше не закрывают открытую категорию;
- дубликаты разделены на наборы, показывают расположение и отмечают кэш как кандидата на удаление;
- отдельная рекомендация «Временные файлы» для кэша, миниатюр и временных расширений;
- информация о занятом пространстве;
- светлая и тёмная темы;
- хорошо различимые иконки в духе Apple: голубые папки и файлы-листы с цветовой маркировкой типа;
- адаптивная и монохромная иконка Android.

Анализ запускается только вручную, читает только подключённую пользователем область и не удаляет файлы автоматически. Для предсказуемой нагрузки один отчёт ограничен 10 000 файлами.

На Android 11 и новее полный режим нужно отдельно включить в системных настройках по кнопке «Весь накопитель». Даже это разрешение не обходит защиту чужих каталогов `Android/data` и не предоставляет системный root-доступ `/`.

Пароль FTP хранится зашифрованным ключом Android Keystore. Обычный FTP не шифрует данные в сети; для защищённого сервера включите FTPS (TLS) в настройках подключения. После глубокой приостановки приложения Android может закрыть сетевой сокет — Aura проверяет соединение и автоматически выполняет повторный вход перед следующей операцией.

Встроенный FTP-сервер принимает подключения только из локальной сети. Он использует обычный незашифрованный FTP, поэтому включайте его только в доверенной домашней сети и останавливайте после передачи файлов. По умолчанию сервер запускается в режиме «только чтение».

## Сборка

Требования: JDK 17, Android SDK 36, Build Tools 36.0.0 и Android NDK 28.2.13676358.

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug lintDebug assembleRelease
```

Готовый отладочный APK создаётся в `app/build/outputs/apk/debug/app-debug.apk`, а компактный оптимизированный APK — в `app/build/outputs/apk/release/app-release.apk`.

На Windows Android Gradle Plugin предупреждает о путях с кириллицей. Проект включает `android.overridePathCheck=true`, но для максимально предсказуемого запуска тестов рекомендуется каталог с ASCII-именем.
