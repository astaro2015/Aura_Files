Официальная схема device-code OAuth проверена по актуальной документации Яндекса 2026-09-06:
- POST /device/code требует client_id;
- обмен device_code на token допускает client_id/client_secret как дополнительные параметры;
- interval/expires_in должны соблюдаться;
- при отсутствии scope токен получает права, заданные при регистрации OAuth-приложения.
