# Aura Files 1.3.1

- «Избранное» превращено в зашифрованный сейф Aura вместо списка ссылок.
- «В избранное» теперь только перемещает файл: исходник удаляется после успешного шифрования.
- Ключ вычисляется автоматически из ANDROID_ID через HKDF-SHA256; нигде отдельно не хранится.
- AES-256-GCM шифрует и метаданные, и содержимое; физические объекты имеют случайные UUID `.avf`.
- Сейф переживает обычную переустановку Aura на том же устройстве при той же подписи/Android user и не открывается штатной Aura после простого копирования на другой телефон.
- Новый экран «Избранное»: открыть, поделиться, вернуть в выбранную папку, удалить.
- `.AuraVault` не показывается в обычном браузере Aura и не индексируется анализатором.
- Папки пока не помещаются в защищённое «Избранное»; действие для них отключено.

- Проверка GCM-тега при расшифровке выполняется явно через `doFinal()`; повреждённый/чужой контейнер не считается успешно восстановленным.
- Неудачное перемещение откатывает созданный `.avf`, чтобы не оставлять лишнюю зашифрованную копию при сохранённом исходнике.
