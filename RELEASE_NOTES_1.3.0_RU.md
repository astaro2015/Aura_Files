# Aura Files 1.3.0

## SPLIT-приложения теперь можно передавать и устанавливать

- Для `SPLIT · N APK` в `Очистка → Приложения` добавлено **«Поделиться комплектом…»**.
- Aura собирает base APK и все установленные splits в один `.apks`.
- Один `.apks` можно отправить через Telegram/почту/Quick Share.
- На другом телефоне Aura открывает `.apks`, проверяет его и устанавливает весь набор одной штатной Android PackageInstaller session.
- В `Очистка → Приложения` добавлена явная кнопка **«Установить .APKS»**: можно выбрать присланный через Telegram файл вручную, даже если Android не предложил Aura при тапе по документу.
- Aura также принимает свой `.apks` через `ACTION_SEND` с фирменным MIME, поэтому доступен путь «Поделиться → Aura Files», когда мессенджер сохраняет MIME.
- Пользователю не нужно выбирать отдельные APK.
- Добавлены SHA-256, package/version/signing/minSdk/ABI проверки и понятные сообщения системных ошибок.
- При необходимости Aura переводит в системное разрешение «Установка неизвестных приложений» и продолжает после возврата.
- Категория APK теперь включает Aura `.apks`.

Ограничение: экспортируется установленный device-specific набор. Данные приложения, OBB и отдельные Play Asset Delivery asset packs не переносятся.
